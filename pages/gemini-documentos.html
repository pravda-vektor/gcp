Gemini con documentos

En esta etapa utilizaremos Gemini para leer un PDF almacenado en Cloud Storage y convertir su contenido a texto plano sin resumir ni interpretar. Esa copia textual será la entrada documental que después leerá el agente.

1. Trabajar con documentos no es lo mismo que trabajar con tablas

Un PDF es una fuente documental no estructurada. Puede contener títulos, listas, párrafos, tablas o incluso páginas escaneadas. Antes de pedir conclusiones, necesitamos comprobar si el contenido fue incorporado y si puede leerse con suficiente fidelidad.

Disciplina del curso Primero identifica y comprende la fuente. Después analiza. Si una parte no puede leerse, la respuesta correcta es reconocer esa limitación, no completar el contenido por inferencia.

2. Comprueba la legibilidad

No todos los PDF son equivalentes. Un PDF con texto seleccionable suele ser más fácil de procesar que un documento compuesto principalmente por imágenes o páginas escaneadas.

PDF con texto legible

El modelo puede acceder al contenido textual y conservar títulos, cifras y listas con mayor facilidad.

PDF escaneado o complejo

Puede necesitar capacidades adicionales de análisis/OCR y siempre requiere revisar con mayor cuidado el resultado.

No completes lo ilegible Para esta práctica, si una parte no puede leerse con certeza, el prompt exige escribir [CONTENIDO NO LEGIBLE].

3. Importar el PDF desde Cloud Storage

En el entorno de Google Cloud utilizado en este curso comprobamos que el chat de Gemini permite usar la opción Importar desde Cloud Storage. Así evitamos descargar el PDF al computador solo para volver a adjuntarlo.

  1. Abre el espacio de chat de Gemini utilizado en el curso.
  2. Inicia un chat nuevo.
  3. Abre el selector para añadir/importar una fuente.
  4. Selecciona Cloud Storage.
  5. Localiza el PDF de la Prueba Tipo.
  6. Confirma que el documento quedó incorporado a la conversación.
  7. Recién entonces ejecuta el prompt de conversión.
Fuente de la Prueba Tipo gs://banco-curso-vertex-datos/alumnos/prueba-tipo/fuentes/criterio_revision_operaciones_digitales.pdf
Interfaz validada en el curso Los nombres exactos de botones pueden cambiar con la interfaz. Si cambia la ubicación del control, conserva la lógica: abrir Gemini → adjuntar/importar fuente → Cloud Storage → seleccionar el PDF correcto.

4. Qué significa convertir PDF → texto plano

En esta actividad convertir no significa resumir. Queremos una representación textual fiel del documento para que otro componente pueda leerla de forma directa.

5. Prompt validado para PDF → TXT

Este es el prompt que utilizamos y validamos para la Prueba Tipo. En la evaluación se debe copiar sin reformularlo innecesariamente.

Prompt validado · PDF → texto plano 
El PDF adjunto es la fuente documental oficial de una evaluación.

Convierte fielmente su contenido a texto plano para que posteriormente pueda ser procesado por otro agente.

Debes cumplir estas reglas:
- No resumas.
- No interpretes.
- No agregues información.
- No elimines condiciones, cifras, títulos ni aclaraciones.
- No reformules el significado de ninguna condición.
- Conserva el código del documento, títulos, subtítulos, listas numeradas, cifras y expresiones relevantes.
- Conserva expresiones como “criterio de revisión”, “revisión adicional” y cualquier limitación expresada en el documento.
- Si alguna parte no puede leerse con certeza, escribe `[CONTENIDO NO LEGIBLE]` en lugar de inferirla.

Devuelve únicamente el texto resultante, sin introducción, explicación, comentarios adicionales ni bloques Markdown.

Ese contenido será guardado posteriormente con el nombre `criterio_revision.txt`.

Antes de finalizar, verifica que el texto represente fielmente el PDF original y que ninguna condición haya sido alterada.

6. Qué deberías observar en el resultado

La respuesta debe contener solamente la representación textual del documento. En nuestro PDF de práctica deberían conservarse, entre otros elementos, el código del documento y las cuatro condiciones simultáneas del criterio.

Comprobación mínima Antes de guardar el TXT, confirma que siguen presentes las referencias a APP/WEB, operación internacional, monto superior a 2.000.000 y producto “Tarjeta de Crédito”, además de la aclaración de que cumplir el criterio implica revisión adicional y no demuestra fraude o incumplimiento.
No corrijas silenciosamente la salida Si una condición desapareció, cambió de sentido o fue resumida, vuelve a ejecutar o corrige el proceso comparando contra el PDF original. La fidelidad documental es parte de la evaluación.

7. Guardar el resultado como criterio_revision.txt

En el entorno que probamos, Gemini mostró el texto resultante en el chat, pero no produjo automáticamente un archivo TXT descargable ni lo escribió de regreso en Cloud Storage. Por eso este tramo es manual.

  1. Copia únicamente el texto resultante.
  2. Guárdalo localmente como criterio_revision.txt.
  3. Abre tu espacio personal en Cloud Storage.
  4. Entra a la carpeta insumos/.
  5. Sube criterio_revision.txt.
  6. Verifica que el archivo quedó en la ruta correcta.
Ruta esperada gs://banco-curso-vertex-datos/alumnos/prueba-tipo/alumnos/alumno-XX/insumos/criterio_revision.txt

8. ¿Por qué convertir el PDF si Gemini ya puede leerlo?

Porque intervienen herramientas distintas. El chat de Gemini puede interpretar el PDF directamente en esta práctica, pero la herramienta de lectura de Cloud Storage utilizada por nuestro agente trabaja de forma más directa y predecible con contenido textual.

PDF original

Se conserva como la fuente documental oficial y permite volver a verificar el contenido.

TXT derivado

Es una representación textual fiel preparada como entrada para el agente.

El TXT no reemplaza conceptualmente al PDF El PDF sigue siendo la fuente original. El TXT es un insumo derivado cuya validez depende de que la conversión haya conservado fielmente el contenido.
