Cloud Storage

Cloud Storage — operaciones

Ahora pasamos de reconocer buckets y objetos a trabajar con ellos. La regla general es simple: antes de crear, mover o eliminar algo, confirma qué recurso estás modificando y si realmente tienes autorización para hacerlo.

1. Antes de modificar un recurso

En un entorno compartido, una acción correcta técnicamente puede ser incorrecta si se realiza sobre el recurso equivocado. Antes de modificar algo, revisa:

  1. ¿Estoy en el proyecto correcto?
  2. ¿Estoy dentro del bucket correcto?
  3. ¿El objeto es mío, de práctica o compartido?
  4. ¿La actividad realmente requiere modificarlo?
  5. ¿Tengo permiso para realizar la acción?
Regla del curso No elimines ni alteres recursos compartidos del curso. Si necesitas practicar copiar, renombrar, mover o eliminar, utiliza una copia descartable o un espacio de trabajo indicado para ese propósito.
Si aparece un aviso de permisos La interfaz puede mostrar avisos de permisos o disponibilidad aunque el recurso del curso siga funcionando. Si el relator indicó continuar y la acción se ejecuta, sigue adelante. Si la operación realmente queda bloqueada, no cambies IAM ni permisos: consulta al relator.

2. Crear un bucket

Crear un bucket es una operación administrativa que no siempre estará habilitada para todas las cuentas de alumno. Cuando la práctica lo permita, el flujo general en la consola es:

  1. Abre Cloud Storage → Buckets.
  2. Selecciona Crear / Create.
  3. Escribe un nombre globalmente único.
  4. Revisa el tipo de ubicación y la región.
  5. Revisa la clase de almacenamiento y opciones de protección.
  6. Antes de confirmar, vuelve a comprobar nombre y ubicación.
  7. Crea el bucket y abre sus detalles.
En la práctica del curso Cuando el relator indique crear un bucket temporal, se utilizará un nombre de práctica y la ubicación indicada para mantener compatibilidad con los demás recursos.
No crees buckets por tu cuenta durante la Prueba Tipo La evaluación utiliza un bucket ya preparado. Este procedimiento es materia de apoyo, no un paso obligatorio de la Prueba Tipo.

3. Crear una carpeta

En la consola de Cloud Storage puedes crear una carpeta vacía o subir una carpeta existente. En buckets con namespace plano, esa estructura visual normalmente se representa mediante prefijos en los nombres de los objetos.

  1. Abre el bucket.
  2. Selecciona Crear carpeta / Create folder.
  3. Escribe el nombre.
  4. Entra en la carpeta antes de subir los objetos que quieras organizar allí.
Ejemplo del curso Una estructura como datos/analitica/ ayuda a organizar objetos, pero debes seguir entendiendo cuál es la URI completa de cada archivo.

4. Subir archivos

Subir un archivo crea un objeto dentro del bucket. La consola permite hacerlo arrastrando archivos al panel principal o mediante Upload → Upload files.

  1. Abre el bucket y entra a la carpeta/prefijo de destino.
  2. Selecciona Subir archivos / Upload files.
  3. Elige el archivo local.
  4. Espera a que termine la carga.
  5. Comprueba que el objeto aparece en la ruta esperada.
Atención con los nombres Subir un archivo con el mismo nombre de un objeto existente puede reemplazar una versión, dependiendo de permisos y configuración. No uses archivos maestros para practicar sobrescrituras.

5. Localizar e inspeccionar un objeto

Encontrar un archivo no es lo mismo que analizar su contenido. Esta operación sirve para responder “¿dónde está?” y “¿qué objeto es?”.

  1. Abre el bucket.
  2. Navega por la estructura visible o usa el filtro/buscador disponible.
  3. Selecciona el objeto.
  4. Revisa nombre, ruta, tamaño, tipo de contenido, clase de almacenamiento y fechas disponibles.
  5. Identifica su URI gs://.
Importante Ver que un objeto existe no demuestra que su contenido haya sido leído o interpretado correctamente. Esta diferencia será central cuando trabajemos con agentes.

6. Descargar un archivo

Descargar recupera una copia del objeto desde Cloud Storage hacia tu computador. El objeto original permanece en el bucket.

  1. Abre el bucket.
  2. Navega hasta el objeto.
  3. Usa el icono o acción Download / Descargar.
  4. Comprueba que el archivo quedó disponible localmente.
En la Prueba Tipo Puede existir un paso donde necesites obtener un documento desde Storage. Sin embargo, si la interfaz de Gemini permite importarlo directamente desde Cloud Storage, no es necesario descargarlo localmente solo para volver a subirlo.

7. Copiar un objeto

Copiar crea un nuevo objeto a partir de uno existente. Es una forma segura de preparar una copia descartable antes de practicar cambios.

  1. Localiza el objeto.
  2. Abre el menú de acciones del objeto.
  3. Selecciona Copy / Copiar.
  4. Indica destino y nombre de la copia.
  5. Confirma y verifica que ambos objetos existan.
Buena práctica didáctica Antes de probar renombrados, movimientos o eliminaciones, crea una copia con un nombre que indique claramente que es descartable.

8. Mover o renombrar un objeto

Cloud Storage permite mover o renombrar objetos desde la consola. Según la operación y el tipo de namespace, una herramienta puede implementar el movimiento como una copia seguida de la eliminación del original, o utilizar una operación atómica disponible para determinados casos.

Renombrar

Cambia el nombre con el que se identifica el objeto dentro de su ubicación.

Mover

Cambia la ubicación lógica o el bucket de destino, según la operación disponible y tus permisos.

Trabaja solo con copias Mover o renombrar cambia cómo se encuentra el objeto. Si otro proceso depende de la URI anterior, podría dejar de encontrarlo.

9. Eliminar un objeto

Eliminar retira un objeto del bucket. Cloud Storage puede disponer de mecanismos de protección como soft delete, pero eso no convierte la eliminación en una operación sin consecuencias.

  1. Confirma que el objeto es descartable.
  2. Selecciona únicamente el objeto que quieres eliminar.
  3. Usa Delete / Eliminar.
  4. Lee el diálogo de confirmación antes de aceptar.
  5. Comprueba que los archivos maestros permanecen intactos.
Nunca uses el bucket compartido para practicar limpieza En el curso, cualquier ejercicio de eliminación debe hacerse únicamente sobre objetos o buckets temporales expresamente autorizados.

10. Lo que sí necesitas para la Prueba Tipo

No todas las operaciones anteriores serán necesarias en la evaluación. Para resolver la Prueba Tipo, las acciones de Storage realmente importantes son:

Localizar el PDF común

Ubicar criterio_revision_operaciones_digitales.pdf dentro de prueba-tipo/fuentes/.

Trabajar en tu carpeta

Utilizar únicamente prueba-tipo/alumnos/alumno-XX/ para tus propios archivos.

Subir el TXT

Guardar y subir criterio_revision.txt dentro de insumos/.

Revisar resultados

Comprobar que el agente creó consulta.sql, resultado.csv e informe_final.md.
