Relación usada en la Prueba Tipo

SELECT
  m.movimiento_id,
  m.cuenta_id,
  m.fecha_movimiento,
  m.canal,
  m.monto,
  cp.cliente_id,
  cp.producto,
  cp.estado
FROM `arched-osprey-506820-i9.analitica_bancaria_demo.movimientos_diarios` AS m
JOIN `arched-osprey-506820-i9.analitica_bancaria_demo.cuentas_productos` AS cp
  ON m.cuenta_id = cp.cuenta_id
ORDER BY
  m.fecha_movimiento,
  m.movimiento_id
LIMIT 20;

Consulta de ejemplo que conserva una fila por movimiento y agrega atributos reales de la cuenta/producto.

Comprueba siempre el grano después del JOIN En la Prueba Tipo queremos conservar una fila por movimiento que cumple el criterio, enriquecida con información de la cuenta/producto.

4. Errores frecuentes

ProblemaQué hacerAyuda
No encuentro un servicio.Confirma proyecto activo y usa el buscador superior de Google Cloud.Navegación
Aparece Access Denied.No intentes modificar IAM por cuenta propia; confirma que estás en el recurso autorizado.Permisos
Confundo bucket con carpeta.Recuerda: bucket = contenedor; objeto = archivo; carpetas visuales pueden ser prefijos.Storage
Preview de BigQuery no coincide con un SELECT.Preview inspecciona filas; una consulta ejecuta lógica SQL explícita.BigQuery
JOIN genera más filas de lo esperado.Revisa cardinalidad, unicidad de la llave y grano antes/después.JOIN
Uso >= 2000000.El criterio de la Prueba Tipo exige estrictamente > 2000000.SQL esperado
Gemini resume el PDF.Usa el prompt PDF → TXT y verifica que no altere condiciones ni limitaciones.Paso 04
El agente ejecuta dos consultas.No pidas un conteo adicional; exige como máximo una llamada a execute_sql_readonly.Paso 06
Preview queda solo en cajas.Revisa qué operaciones terminaron y usa el prompt de recuperación adecuado.Paso 07
Aparece 429 / Resource exhausted.Reintenta más tarde si no hubo ejecución previa; no “recuperes” trabajo inexistente.Cuota

5. Glosario

Agente

Configuración reutilizable con instrucciones persistentes y capacidades opcionales.

Alcance

Qué pregunta puede responderse y con qué evidencia disponible.

BigQuery

Servicio analítico de Google Cloud para organizar datos en datasets/tablas y consultarlos.

Bucket

Contenedor principal de objetos en Cloud Storage.

Criterio

Regla o condición explícita contra la que se compara la evidencia.

Dataset

Contenedor lógico de tablas y otros recursos de BigQuery dentro de un proyecto.

Evidencia

Contenido o datos efectivamente consultados que respaldan una afirmación.

FARO-4

Fuentes → Alcance → Resultado → Observación.

Grano

Qué representa exactamente una fila de una tabla o resultado.

GoogleSQL

Dialecto SQL utilizado por BigQuery.

gs://

Esquema de URI utilizado para referirse a buckets y objetos de Cloud Storage.

Instructions

Reglas persistentes que definen cómo debe trabajar un agente.

Interpretación

Lectura razonada que conecta criterio y evidencia sin sobrepasar las fuentes.

JOIN

Operación SQL que relaciona filas de tablas mediante campos compatibles.

Knowledge

Referencia estable asociada al agente; no debe confundirse con el caso variable.

Llave

Campo utilizado para identificar registros o relacionar tablas.

Objeto

Archivo almacenado en Cloud Storage junto con sus metadatos.

Preview

Vista de Agent Studio para probar el agente y observar respuestas/eventos antes del despliegue.

Prompt

Instrucción concreta que indica qué tarea debe realizar el modelo y bajo qué condiciones.

Schema

Definición de columnas, tipos y modos de una tabla de BigQuery.

Tool call

Solicitud del modelo para ejecutar una herramienta con argumentos determinados.

Tool result

Respuesta de la herramienta a una llamada; no es una segunda ejecución por sí sola.

Trazabilidad

Capacidad de relacionar una afirmación con su fuente, cálculo o resultado.

Variable binaria

Categoría con dos estados; por ejemplo es_internacional codificado 0/1.

Variable ordinal

Categoría cuyos niveles poseen orden; por ejemplo Bajo < Medio < Alto.
